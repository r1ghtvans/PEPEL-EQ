# Pepel EQ (VST3, Windows)
1. Создайте на GitHub пустой репозиторий, загрузите в него содержимое этой папки (Add file -> Upload files).
2. Файл `.github/workflows/build.yml` создайте кнопкой Add file -> Create new file, введя путь целиком, и вставьте содержимое.
3. Вкладка Actions -> дождитесь зелёной галочки -> внутри запуска скачайте артефакт `Pepel-EQ-VST3`.
4. Папку `Pepel EQ.vst3` положите в `C:\Program Files\Common Files\VST3`, в FL Studio: Options -> Manage plugins -> Find plugins.
